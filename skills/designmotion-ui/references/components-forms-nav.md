# Micro-interactions, Forms & Navigation (`@designmotionhq`)

Covers **42 canonical rules**: Micro-interactions (`15`), Forms (`15`), Navigation (`12`).

---

## 1. Micro-interactions (`MI1–MI15`)

1. **`skeleton-y-carga` (Latency ladder & content-aware skeletons):** `<300ms`: render nothing (avoid flash); `>300ms` known layout: skeleton mirroring exact content geometry (circle avatar, name bar, text lines) with `left -> right` shimmer and `0` layout jump; `<3s` unknown duration: local spinner (never full-page); `>3s` measurable: non-linear progress bar (fast start, slower end).
2. **`optimistic-ui-limites` (Optimistic UI boundaries):** Apply instant optimistic updates (`<400ms` perceived threshold—e.g. `44ms` vs `720ms` feels broken) with silent rollback on error **only** on cheap reversible actions (`~99%` success: like, favorite, rename). **Never** use on money, inventory or atomic commits—show spinner and update only after real `200 OK`.
3. **`presencia-colaboracion` (Typing & multiplayer presence):** Tie typing indicators strictly to real keystroke activity (`1.5s`, never linger `6s`); interpolate remote cursors from `10 Hz` to `60 fps`, derive color deterministically via `hash(user_id)`, stack avatars (`3` + `+N`), lock selected objects against conflicts, and support avatar-click `Follow mode`.
4. **`toasts-notificaciones` (Severity-to-surface & toast stack):** Toast (`4s` info + `Undo` if destructive, `7s` warning, persistent error) placed bottom-right desktop / top mobile (never center), max `3` visible with spring (`stiffness: 180, damping: 20`), always dismissible, pairing icon + colored left border (`6%` miss background tint alone); persistent manual Banner for system degradation; blocking Modal only for critical decisions; passive Badge for counts.
5. **`undo-friccion-destructiva` (Friction by cost & Red Budget):** Match friction to cost: soft-delete (`30d` trash) + `Undo` toast (`5s`), editor `Cmd+Z` stack, `10s` send grace period. For destructive actions: explicit verb (`"Delete draft"`, never `"Yes"`), separate from primary CTA spot, `red budget = 1` per view, isolate in bottom `Danger Zone`, and use hold (`300ms`), cooldown (`14d`), or type-to-confirm only when truly irreversible.
6. **`estados-de-exito` (Specific success & open loops):** Replace generic `"Success! OK"` with exact outcome (`"Invoice sent to Northwind Labs"`), offer `1–2` next actions, match dismissal to stakes (`2.6–4s` toast on low-risk saves; persistent receipt page on payments), leave one open loop (`Notify me when paid`), and reserve confetti strictly for rare milestones.
7. **`copy-to-clipboard` (Instant copy & `aria-live`):** Flip icon immediately to check (no spinner), reset after `2s`, copy raw unformatted value (no newlines/zero-width chars), announce `"Copied"` via `aria-live="polite"`, and fall back to `document.execCommand('copy')` on insecure origins.
8. **`cta-conversion` (High-converting CTA style):** Combine trustworthy brand color (`#6366f1`), crisp white contrast, generous padding, friendly `14px` radius, `Inter` `600` weight, tinted shadow (`0 4px 20px rgba(99,102,241,0.4)`), and subtle hover scale.
9. **`drag-drop-kanban` (DnD & Kanban):** Show 3 pickup signals (cursor, lifted shadow + `3°` card tilt, dimmed background), render a full-height placeholder slot (never an ambiguous thin line), choose grid snap vs free drop, display WIP limits in column headers (`4 / 4`), collapse secondary columns vertically to avoid horizontal scroll, prefer swimlanes over a second board, and back drops with `5s` `Undo`.
10. **`gestos-moviles` (Swipe & Pull-to-refresh physics):** Apply `~0.5x` rubber-band resistance (`finger 208px -> moved 104px`); use 2 swipe thresholds (short pull reveals buttons, long pull commits on release with `1` haptic tick), mapping right=safe / left=destructive; teach swipe once with a `Launch 1` peek hint + `5s` `Undo`; settle pull-to-refresh with overshoot while keeping scroll alive.
11. **`grabacion-voz` (Hold-to-record voice notes):** Start timer + swell button past thumb on press; cross a left cancel line to discard on release; allow slide-up lock for long recordings with `Stop`; render live mic waveform (flat line = muted mic); support scrubbable playback with `1x / 1.5x` speed toggle.
12. **`rating-estrellas` (Ratings):** Separate hover preview layer from committed value, clip partial stars for exact fractional averages (`4.4`, `4.5`), stagger fill `30ms` left->right, and summarize distributions with a continuous ring.
13. **`badges-notificacion` (Unread badges):** Pin badge to icon corner so icon never reflows (`48px` drift), cap at `99+`, never combine dot + numeric count on the same row, clear immediately on view open (never flash `0`), and badge only actionable items.
14. **`seleccion-multiple` (Multi-select):** Tri-state header checkbox (`empty / partial / checked`, clicking `partial` selects all), name real total (`"Select all 247 matching"`), support `Shift+click` range selection, persist `selectedIds` in global state across pagination, echo count on bulk actions (`"Delete 247"`), and offer `10s` `Undo`.
15. **`tooltips` (Contextual tooltips):** `300ms` hover delay (`0ms` is noise), directional arrow toward trigger, auto-flip at viewport edges, close on mouseleave/`Esc`/blur/tap-outside, `max-width: 300px`, single sentence max. *(See `N11` `500ms` shortcut tooltip variant.)*

## 2. Forms & Controls (`F1–F15`)

1. **`estados-input-y-labels` (6 input states, labels & anti-CLS):** Implement all 6 states: Default (visible label outside + helper), Focus (ring `>=3:1`, e.g. `4.6:1`), Error (color + icon + message—`12%` color-vision deficiency misses red border alone), Success (inline green check), Disabled (solid muted gray, never `opacity: 0.5`), Loading (internal spinner + disabled input). Reserve fixed space below inputs (`0px` submit shift, avoiding `90px` jumps), style `input:autofill` for dark mode, use benefit-driven CTA copy (`"Create my free account"` `93%` vs `"Submit"` `19%`), and use `inputmode="numeric" pattern="[0-9]*"` for codes (never `type="number"`).
2. **`validacion-onblur-errores` (Validation timing & escalation):** Validate `onBlur` (never on first keystroke), escalate only errored fields to live `onChange` so red clears immediately when fixed, confirm valid fields with green check, and route errors by severity (`Inline` recoverable cuts errors `80%` -> `Toast` transient -> `Modal` blocking) with human cause + recovery action (`Retry`/`Contact`). *(Submit disabled-vs-live conflict tracked in tensions doc.)*
3. **`botones-doble-envio` (Button rules & idempotency):** Tap target `>=44px`, concrete action verb (`"Create workspace"`), `1` solid primary per context (`Cancel` ghost), visible keyboard focus ring (never `outline: none`), lock width during loading (`0px` CLS), guard handler with `inFlight` + `Idempotency-Key` (`Requests sent: 1`), morph to check or inline error, and never leave a disabled button unexplained (`"Name your workspace first"`).
4. **`wizard-multipaso` (Multi-step forms):** Split long forms (`12` fields -> `4` steps by context, ~`3` fields/step), show progress, validate inline per step blocking `Next` on error, and persist state across step navigation/refresh.
5. **`autoguardado-offline` (Autosave state machine):** Debounce `~800ms` after typing stops, drive indicator from an honest 5-state machine (`Typing / Saving / Saved / Offline / Error`), queue offline edits FIFO to drain in order on reconnect, detect multi-tab conflicts without silent overwrite, and block tab close while writes remain pending.
6. **`controles-seleccion` (Switch / Checkbox / Radio / Segmented):** `Switch` acts immediately without Save (rail `~2×` knob diameter, padding `≈` knob radius, `250ms ease-out`, `Space` + `aria-checked`, optimistic flip with spinner); `Checkbox` applies on Save (`el.indeterminate = true` in JS for mixed parent); `Radio` for `<=5` options (`Dropdown` if `>5`); `Segmented control` for `2–4` exclusive visible options; wrap `<label>` around the full `>=44px` row (not `16px` box alone).
7. **`dropdowns` (Select/Dropdown):** `>=44–48px` trigger with caret + hover, auto-flip upward near viewport bottom, full keyboard nav (`↑/↓/Enter/Esc`), inline search past `10` items, virtualization past `100`, `~150ms` animation (`50ms` too fast, `500ms` sluggish).
8. **`sliders` (Range & stepped sliders):** Extend hit target across the full row (`4px` visual track is too small), fill track left of thumb, snap to discrete steps when decimals aren't needed (e.g. `25`), float live value above thumb while dragging, and support arrow keys + `Home`/`End`.
9. **`date-range-picker` (Date ranges):** Add quick presets covering `~90%` of cases (`6 clicks/5s` -> `1 click/1s`), show hover preview + drag handle refinement, display `2` months side-by-side (`3` widescreen), support direct typing + full keyboard (`PgUp` month, `Shift+PgUp` year), and open as a full-screen sheet on mobile.
10. **`file-upload` (Drag-and-drop uploads):** Show 3 drag-over signals (border, glow, copy change), replace mysterious spinners with `% + ETA + MB/s`, keep failed file queued for 1-tap retry, render file thumbnail/type/size, and run independent per-file upload queues.
11. **`tarjetas-credito` (Card input):** Group `4-4-4-4` while preserving caret position during middle edits, detect card brand from digit `1` (`4` Visa, `5` Mastercard, `3` Amex), validate `onBlur` (never mid-typing), strip pasted dashes/spaces, and keep raw digits separate from display mask.
12. **`otp-input` (OTP 6-digit boxes):** Back all `6` slots with one string (`useState("847291")`), support full paste stripping spaces, smooth auto-advance + backspace, `inputmode="numeric"` + `autocomplete="one-time-code"`, `30s` resend cooldown, and shake + clear + refocus on wrong code.
13. **`passwords` (Password UX):** Favor length/entropy over rigid symbol rules (`8 chars + 1 symbol` cracked in `2h`), show live checklist + strength meter while typing, include visibility toggle, always allow `paste`, and support 1-tap password manager autofill.
14. **`prompt-ia` (AI prompt composer):** 4 structural layers: `Attachments` (uploads inline at top), `Text field` (grows upward), `Toolbar` (never moves at bottom), `Container` (focus ring with zero border jump); enable `Send` only with content and swap to `Stop` while generating.
15. **`edicion-inline` (Click-to-edit):** Signal editable text on hover, match exact font/size/padding with transparent border when active (`CLS 0.000`, `46 = 46`), support `Enter` (save) / `Esc` (cancel), fix one consistent `blur` rule matched to typo cost (use explicit `Edit` mode on invoices/numbers), and save optimistically with rollback.

## 3. Navigation (`N1–N12`)

1. **`arquitectura-nav` (App shell & toolbars):** Mobile `Tab bar` (`3–5` destinations); Desktop persistent `Sidebar` (`5+` sections); keep hamburger strictly for mobile secondary nav (`-40%` clicks / `-56%` desktop engagement NNG 2018); `Cmd+K` as power-user shortcut (never sole nav for new users); `Breadcrumbs` at `depth > 2`; Toolbars capped at `3–5` everyday tools with text labels beneath each icon, grouped by task, `1` accented primary action, rare tools in `More`, and keyboard shortcuts for experts.
2. **`command-palette` (`Cmd+K` & Raycast-style launcher):** Fuzzy-highlight matches, group results (`Recent, Actions, Pages`), show recent commands on empty query, keep cached results live while streaming updates via subtle progress line (`~40ms` perceived latency, no blocking spinner), show bottom key hints (`Enter` / `Cmd+K`), blur background (`~20px` instead of heavy `60%` dim), full keyboard nav, and `Esc` stepping back `1` submenu level.
3. **`tabs-horizontales` (Tabs):** Slide active indicator (`~280ms` spring), scroll horizontally with edge fades on overflow (never wrap to 2 lines), support `←/→/Home/End/Tab`, adapt mobile (`<5` segmented control, `>5` bottom sheet), and crossfade content with `80ms` pause and fixed height.
4. **`filter-chips` (Filter chips):** Distinguish `idle / active / disabled`, apply `OR` within a group and `AND` across groups, update result count in the same frame on tap, switch `>10` chips on mobile to 1 horizontal scrolling row with edge fade, pin active chips first, and provide one `Clear all` with active count.
5. **`menus-contextuales` (Context menus):** Measure viewport bounds before opening (vertical flip / horizontal mirror), group by intent (`3` groups + isolated `Delete` in red last), implement safe `hover intent` triangle from cursor tip to submenu edge, full keyboard (`↑/↓/typeahead/Esc 1 level`), and mobile `long-press (500ms)` opening a bottom sheet.
6. **`sheets-vs-modales` (Sheets vs Modals):** Use `Sheet/Drawer` when the page behind must stay visible for reference; `Modal` with scrim only for full-stop focus. Use `3` snap points (`peek / half / full`), dismiss on either `velocity > threshold` (flick) or `distance > 50%`, convert to bounded desktop side drawer (`320px <= width <= 40%`; `240px / 17%` breaks forms), and replace content in place instead of stacking `2` sheets.
7. **`tree-views` (Tree views):** Indent `16px` per depth level with vertical guide lines, rotate the same chevron `90°` (don't swap glyphs), implement `role="tree"` + `aria-expanded` + `↑/↓/→/←`, fetch lazy children with local skeleton rows (never lock entire tree), and spring-load closed folders after `600ms` drag hover.
8. **`busqueda-autocompletado` (Search & mobile wizard search):** Desktop 5 pieces: descriptive placeholder, recent searches on focus, top `3` popularity-ranked suggestions with badges (better than `10`), `2px` visible focus ring (WCAG 2.4.7), and helpful alternatives on `0` results. Complex mobile search (Airbnb-style): full-screen sheet (`1 screen = 1 task`), step-by-step accordion (`Where -> When -> Who`), live result count on CTA, thumb-zone floating `Map/List` pill, and preloaded recents/nearby.
9. **`paginacion-scroll` (Pagination & scroll restoration):** Use cursor pagination (`?after=cursor`) for live/dynamic feeds; choose numbered (jump to page `500` with `first · gap · current · gap · last` truncation), Load More (user control), or infinite scroll (feeds—never bury legal footer); sync page to URL; set `history.scrollRestoration = 'manual'` restoring `scrollY` minus sticky header height; add `scroll-margin-top` on `:target` anchors.
10. **`settings-ux` (Settings architecture):** Match save model to risk (instant toggles for preferences vs `Save/Cancel` bar for identity/billing), group by user task (not org chart), add settings search, mark modified overrides with a dot + 1-click `Reset`, and quarantine destructive actions in bottom `Danger Zone` with exact-name type-to-confirm.
11. **`atajos-teclado` (Discoverable shortcuts):** Show keys right-aligned on every menu row, repeat the same key in `500ms` hover tooltips, show `1` quiet tip right after the action only after `3` mouse uses (never on 1st click), enforce `1` shortcut per action everywhere, and disable single-key shortcuts while focused in text inputs.
12. **`breadcrumbs` (Breadcrumbs):** Make every level a link except the current page (whose label matches the page title), fold only middle levels into a menu past `4` levels keeping both ends (`Home / ... / Invoices / INV-2041`), and show a `>=44px` parent back link on mobile.
