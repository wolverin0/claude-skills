# Layout, Typography, Color & Motion (`@designmotionhq`)

Covers **32 canonical rules**: Layout & Systems (`20`), Typography (`2`), Color & Surfaces (`6`), Motion (`4`).

---

## 1. Layout & Spacing (`L1–L20`)

1. **`espaciado-cards` (Airy white space):** Raise card padding (`8px -> 28px`, or `16px -> 32–40px`), block `gap` (`4px -> 18px` or `8px -> 16–22px`), body `line-height` (`1.1 -> 1.6`), and action icon spacing (`2px -> 28px`). Distinguish micro (padding), macro (`23px -> 48px` between sections), and active white space. *(Conflicts with `L9` Linear density.)*
2. **`ley-proximidad` (Proximity without dividers):** Keep related items `8–12px` apart (`8px` in toolbars, `12px` inside form groups) and separate distinct groups by `32–40px` (`32px` toolbars, `40px` form sections) instead of adding hairline dividers.
3. **`tokens-design-system` (Minimal 5-layer tokens):** Before screens, define semantic color roles (`bg`, `surface`, `text`, `muted`, `primary`), spacing scale (`4px` base: `4, 8, 16, 24px` OR `8px` base: `8, 16, 24, 32, 48px`), `4` fixed type sizes, concentric radii, `2` shadow levels (`shadow-sm` card, large float), and one `Finish` rule (borders OR shadows OR flat—never all three).
4. **`proporcion-aurea` (Golden Ratio `1.618`):** Derive organic spacing (`8, 13, 21, 34, 55px`), asymmetric layout splits (`61.8%` content / `38.2%` actions), and type steps (`16, 26, 42, 68px`) by multiplying by `1.618`.
5. **`grilla-12-columnas` (12-col ratio system):** Use `4+8`, `6+6`, `3+9`; collapse across breakpoints (`12 -> 6 -> 4 -> 1`); choose intentional gutters (`8px` technical, `24px` balanced, `40px` editorial); break the grid only on focal elements.
6. **`border-radius` (Concentric corners & personality):** Match radius to tone (`~8px` SaaS/Enterprise, `~20–32px` friendly consumer); use one closed scale (`4 / 8 / 12 / 16 / 9999`), reserving `9999` strictly for single-line pills/toggles/avatars and `0px` for edges touching the viewport. Apply `inner = outer - border - padding` (`24 - 2 - 8 = 14`), `outer = inner + gap` (`8 + 2 = 10`), `thumb = track - inset` (`12 - 4 = 8`), and round edge images only on touching corners (`24px 24px 0 0`).
7. **`correcciones-opticas` (Optical > math):** Shift Play triangle right (`w / 6` per `De_s4pZCuJk` or `+8%` bbox per `DVqncGUjLec`); make circles larger than squares (`+11%` `20px vs 18px` or `×1.13`); align icons to label `cap height` with an `em` nudge (`translate: 0 .05em`, or `+2px` button text lift); drop dark-mode `font-weight` by `1` step; use `tabular-nums`.
8. **`contencion-cards` (Card containment & anti-slop dashboards):** Use cards only for navigable entities (`1` entity, `1` title, entire surface clickable, `16:9` cropped media, never nested). Treat cards by background: border on white, shadow on tinted, flat inside a panel, border+tint in dark mode. In project/metric dashboards: remove pastel icon tiles and decorative gradients, keep `1` hero metric + `3` secondary, show status with dot + 1 word (`Ready/Building/Error`) without tinting the card, replace `"Welcome back"` with real date range, use `mono` only for copyable hashes/domains, `1` solid primary CTA + ghost secondary, and overflow actions in `...`. *(Careful: see `product-ux-audit` precedence for high-frequency ERP rows.)*
9. **`densidad-linear` (Linear precision mode):** For expert tools: `13px` text, `32px` rows, `-1%` tracking, `0` shadows via 3 surfaces (`#0B0D10 / #13161B / #1A1E25`) + `1px` borders at `8%` white, single accent color, `16px` icons instead of colored pills, visible keycaps, `4px` grid, `80ms` hover, `<=150ms` transitions, `0` overshoot.
10. **`paneles-redimensionables` (Resizable split panes):** Render a `1px` divider with `12px` grab target, clamp between `min` and `max` (`240px–640px`), snap cleanly to closed near edge (never `44px` slivers), cover iframes/page with an invisible drag overlay, set `body { cursor: col-resize }`, and persist width.
11. **`css-has` (Zero-JS container state):** React purely in CSS using `:has(:checked)`, `:has(:user-invalid)`, `.app:has(aside) { grid-template-columns: 280px 1fr }`, quantity queries (`:has(> :nth-child(n + 5)) { --density: compact }`), and `body:has(dialog[open]) { overflow: hidden }`.
12. **`css-nativo-moderno` (Modern CSS replacing JS/hacks):**
    - Fixes: `min-height: 100dvh` (not `height: 100%`); `flex`/`grid` + `gap: 24px` (not `margin-bottom`); `font-size: clamp(1.5rem, 4vw, 3rem)` (not stacked media queries); `isolation: isolate; z-index: 1` (not `z-index: 9999`); `display: grid; place-items: center` / `align-content: center` (not absolute `top: 50%`); `@layer base, components, utilities`.
    - Native features: `scroll-behavior: smooth`, `@media (prefers-color-scheme: dark)`, `.truncate` ellipsis, `position: sticky; top: 0`, `scroll-snap-type: x mandatory`, `AccentColor` / `AccentColorText`, `@container`, `subgrid`, `@view-transition { navigation: auto; }`, CSS Nesting, `h1..h3 { text-wrap: balance }` / `p { text-wrap: pretty }`, and CSS Anchor Positioning (`anchor-name` / `position-anchor`).
13. **`sistema-iconos` (Icon grid & crispness):** Draw all icons on a `24×24px` grid with `20×20px` live area (`2px` padding measured from outer stroke edge; centerlines `3..21`), single `2px` stroke width with `round` caps and joins (never mix `1.5` and `2`), whole integer pixel coordinates (`x = 2`, never `x = 2.5`), and only 3 sizes matched to text (`16px` for `12–13px`, `20px` for `14–16px`, `24px` for `18px+`, authored per size).
14. **`blindaje-texto-real` (Real-data text hardening):** Always test `empty`, `1 char`, `40 chars + emoji`. Set `min-width: 0` on shrinking flex children, middle-truncate filenames/emails (`...pdf`), set `font-variant-numeric: tabular-nums` on changing metrics, and `overflow-wrap: anywhere` on URLs/IDs.
15. **`mobile-375` (`375px` mobile rules):** Collapse tables to cards under `<640px`, keep `+`/`€` attached to their number, set `font-size >= 16px` on inputs (prevents iOS auto-zoom) + `inputmode`/`autocomplete`, apply `min-height: 44px` inside `@media (pointer: coarse)`, and reserve bottom `safe-area` + scroll padding under fixed bars.
16. **`tablas-datos` (Desktop & container-responsive tables):** Right-align numbers (`tabular-nums`), left-align text, put `—` in empty cells, use hairline dividers + row hover (zebra stripes only on `>=12` cols), offer row densities (`Compact 40px`, `Default 48px`, `Comfortable 56px`), sticky header + first column (`position: sticky; left: 0; top: 0`), reveal row actions on hover/focus (kebab on touch), and collapse to 2-line cards via `@container (max-width: 700px)` with tap-to-expand details.
17. **`chat-ui` (Chat layout):** Group same-author messages `<2 min` apart (`4px` intra-group, `16px` inter-group), show date dividers and time on hover, insert optimistic bubbles with inline `Retry` (0 spinners), never hijack scroll while reading history (show unread pill), render typing indicator inside message flow (not above composer), cap composer at `5` lines before internal scroll, and use `20px` icons next to `16px` body.
18. **`calendario-semanal` (Weekly `7×24` calendar):** Style events with a `3px` left stripe + `10%` background fill (never solid opaque blocks), place overlapping events side-by-side (`1/2`, `1/3` width, 0 hidden), scale height linearly (`1h = 60px`, clip titles from `15m`), snap drag/draw to `15m` (resize bottom only), and pin all-day events in a sticky top row.
19. **`avatares` (Avatar system):** Fallback chain `Photo -> 2 Initials -> Icon` (`1` initial only when tiny), deterministic hue from `hash(user_id)`, online ring on avatar border (never a second floating badge), stack teams with `+N` overflow, and standardize 3 token sizes (`24 / 32 / 40px`).
20. **`fintech-balance` (Banking/fintech flow):** Make balance the largest text on screen (`€2,418.60`), prefix every row with `-` or `+` (refunds), put a dedicated Review screen before sending (recipient, amount, fee, arrival), show live step progression (`Sent -> Processing -> Completed`), and place `Freeze` (`1 tap to freeze, 1 to undo`) directly on the card screen.

## 2. Typography (`T1–T2`)

1. **`sistema-tipografico` (Domain font, modular scale & measure):** Never ship default `system-ui, sans-serif`. Pick `1` family fitting the domain (`Geist` tech, `IBM Plex Sans` dense enterprise, `Manrope` friendly consumer, `Satoshi` editorial, `Bricolage Grotesque` craft, `Inter` safe default), verify `.woff2` network load (`200`), `tabular-nums`, and license (`SIL OFL` vs `Fontshare`). Keep a strict modular scale (`1.2` rounded `16, 19, 23, 28, 33, 40, 48px` OR `1.25` `12.8..48.83px`), `2–3` weights max (`400/600`, `400/700`, or `800/400/300`), shrinking `line-height` as size rises (`1.5` body, `1.2–1.4` subheads, `1.1` display/headings), role-based tracking (`-0.02em` headings `>=24–39px`, `0` body, `+0.05em`–`+0.06em` small caps), and cap line width (`50ch–60ch`, `45–75ch` comfort band, `66ch` optimal).
2. **`numeros-tabulares-tiempo` (Tabular figures & time format):** Enforce `font-variant-numeric: tabular-nums`, right-align numbers, abbreviate large counts (`1K`, `1M`) with exact value on hover, use relative time under `<24h` (`2h ago`) and absolute older than 24h, and pin the currency symbol (`$`) to the left edge so decimals align vertically.

## 3. Color & Elevation (`C1–C6`)

1. **`regla-60-30-10-acento` (`60-30-10` + 1 accent):** Allocate `60%` dominant base, `30%` lighter same-hue surface (`#0f172a` -> `#1e293b`), and `10%` single accent color (pop-out effect over neutrals like `#808080`); verify simultaneous contrast and semantic hue temperature (red=danger/urgent, blue=trust, green=success).
2. **`paleta-oklch` (OKLCH scales):** Build `10`-token scales in `OKLCH` (`L 0.35–0.75`), validating `3:1`, `4.5:1 AA`, and `7:1 AAA` at pick time; preserve `5` recent swatches + checkerboard alpha preview.
3. **`gradientes-oklch` (Vivid gradients):** Interpolate in `oklch` (`linear-gradient(in oklch 90deg, #3b5bdb, #f5d90a)` -> `#00c3ad`) or insert a manual middle stop; keep sRGB stops `<=60°` apart at `135deg` or use mesh gradients; add subtle grain on large dark gradients to prevent banding; apply gradients only to headlines (never body text); keep lightness close behind text (`8.2:1`).
4. **`dark-mode-superficies` (Stepped surfaces, 3 whites & hairlines):** Never invert `#000`/`#FFF`. Step 4 surfaces (`0 page #0B0D10`, `1 card #13161B`, `2 menu #1A1E25`, `3 modal #222730`), use 3 white opacities (`87%` primary, `60%` secondary, `38%` disabled), desaturate/lighten accents, use `1px rgb(255 255 255 / .08)` borders, dim photos (`brightness(90%)`), and provide dark illustration variants.
5. **`sombras-elevacion` (Stacked directional shadows vs dark mode):** Use one top light source (`x: 0`, positive `y`). Never use single `25%` pure black shadows. Stack 2 layers: tight contact (`0 1px 2px`) + soft ambient lift — either background-tinted at `~8%` (`rgba(24,24,27,.08)`) or neutral with negative `spread` trimming side halos (`--shadow-1`: `0 2px 6px -2px`; `--shadow-2`: `0 6px 16px -4px`; `--shadow-3`: `0 16px 40px -8px` at `.08`). In dark mode, either drop shadows (`#18181B` lighter surface + `1px` top border) OR use brand-tinted 3-layer glow (`0 0 60px rgba(139,92,246,0.15)`) + 3D hover perspective on showcase cards.
6. **`glassmorphism` (4 CSS properties):** Combine low-opacity `rgba` background, `backdrop-filter: blur(...)`, `1px` translucent white border, and soft `box-shadow`.

## 4. Motion & Animation (`M1–M4`)

1. **`easing-spring` (Physical easing):** Never use `linear` for UI transitions. Use `ease-out` or `spring`, immediate hover (`scale +5%`) and tactile press (`0.95x -> 1.05x`), ripple feedback, and anticipation (`squash` + bounce).
2. **`duraciones-por-rol` (Duration budget):** Calibrate by role: Entrance `200–300ms` (`250ms`), Exit faster `150–200ms` (`150ms`), Feedback `<100ms` (`50ms`), Attention/Alerts `500–800ms + bounce`, list stagger `50ms`/item. *(Conflicts with `L9` Linear mode: `80ms` hover, `<=150ms`, `0` overshoot.)*
3. **`modales-fisicos` (Physical modals):** Enter with spring + internal stagger (`+0f/+5f/+10f/+15f`), exit smoothly to non-zero scale (`scale(0.95) + opacity(0)`), blurred backdrop + deep shadow.
4. **`view-transitions` (Native View Transitions API):** Assign unique `view-transition-name` per morphing item with `document.startViewTransition()` (SPA) or `@view-transition { navigation: auto; }` (MPA) for card->page morphs, list reordering, circular theme toggle wipes (`600ms` `clip-path: circle(...)`), and button-origin modals (Chrome `126+`, Safari `18.2+`).
